## 〇、双池锚点（v1.1 全案逻辑起点）

**关系报告的每一步分析，都从两个词池的并置与碰撞出发。**

### 锚点定义

| 词池 | 来源 | 内容 | 口径 |
|---|---|---|---|
| **词池 A（我的池）** | 自测卷 | 自测主型行 ∩ 自测答"是"词 | 我对自己的判断 |
| **词池 B（TA 的池）** | 他测卷 | 他测主型行 ∩ 他测答"是"词 | **你眼中的 TA**（投射口径） |

**A + B = 全关系报告的唯一证据基础。** 报告里出现的每一个判断、每一句描述、每一个动作，都必须能追到这两个池子里的词；池外内容（副型词/低分行词/未答是词/两卷之外的推断）一律不进报告。

### 锚点三条规则（写作与引擎共同遵守）

1. **双池分立、标签随行**：池 A 的词只描述"我"，池 B 的词只描述"TA"；引用时必须带来源标签——「你确认了『___』（自测）」/「你判断 TA 有『___』（他测）」。两池不混用、不互相解释。
2. **关系分析 = 两池碰撞，产出「层面生克图谱」（v1.2 核心规格）**：
   - **关系判定**：自测主行 × 他测主行 → 按固定生克环定关系（相生：木生火/火生土/土生金/金生水/水生木；相克：木克土/土克水/水克火/火克金/金克木）+ 同行自对；
   - **原因说明**：这组生克的机制（预置文案）；
   - **生克点**：判定二者**在哪些层面相生、哪些层面相克**——层面按三段（阳 L1–3 / 中 L4–6 / 阴 L7–9，两池词天然归段）切分；每个生克点 = **一个词对**（池 A 一词 × 池 B 一词）+ 生/克判定 + 原因；
   - **对应策略**：生点 → **拔阴取阳**（自己身上可执行：把自己池中相应阴面词拔向阳面，守住这个生点）；克点 → **化克为生**（养第三行：落到人/制度/动作/时机载体，化解这个克点）；策略句式全部围绕词对：「你的『___』× TA 的『___』」；
   - **实现机制**：engine_rel 的 kePairs（源词克靶词）扩展为「证据对 + 层面标注 + 生克价」——两池词按层面配对、按预置判定矩阵定生克价、按词对出策略，**引擎可全自动生成**（判定矩阵见 R3.5）。
3. **他测池天生带投射口径**：池 B 的措辞一律写「在你眼里，TA 是【X】行 / 你判断 TA 有『___』这类词」，不写「TA 就是 X 行人」。这与八块模板"三种数据来源"表咬合：自测+我眼中的他 = 有投射偏差，**报告明说**。

### 锚点与现有引擎的兼容性（高）

- **computeRelation 的词级证据对**（源词克靶词）本就是"A 池词对 B 池词"的碰撞实现——锚点规则 2 零改造；
- **scopeRows 双方主行词库**本就按双方主行收词——双池分立天然成立；
- **唯一要做的引擎增强**：报告侧引用词时输出来源标签（自测/他测）——现有四象限已按"我的词/TA 的词"分列，补标签即可。

### 锚点带来的结构收益

- **单方他测模式（主形态）**：同一个人填两卷（自测 + 站在对方角度他测）→ 报告完整成立：我的形状（池 A）+ 我眼中的 TA（池 B）+ 两池碰撞（生克/卡点/功课）。不依赖对方参与——八块模板"他测"专节原话："这不是妥协，是采样了两个视角"。
- **双向对填（增强形态）**：对方也做了自测卷 → 两个升级解锁：
  ① **主型级差值**：TA 自测的主型 vs 我他测 TA 的主型——差 = 关系里最大的误解，比词级差值更直接；
  ② 可信度升档标注（三源表：双向对填最准）。

## 一、先定性：八块模板是什么、和现有框架什么关系

**八块模板是一份「纯关系报告」的骨架**——落点"我们之间"，与自测报告（落点"我"）分开。**现有 B 模式（M12 关系篇）只是它的子集**：

| 维度 | 现有 B 模式（M12） | 八块模板 |
|---|---|---|
| 结构 | 四象限/生克分型/证据对/关系层级/功课包，挂自测报告主干尾部 | 独立成篇八块，速览在前、功课在后 |
| 速览 | 无 | **七行一页 + 灵魂句**（全篇成败所系） |
| 卡点 | 只到"你们是金克木" | **五种断法定位到环节** + 修复动作 |
| 数据来源意识 | 无标明 | **三源标明 + 单方可信度降档** |
| 关系功课 | 功课包 | 按断法一句话 + B=MAP 一个微行为 + 复盘预约 |
| 化克为生 | 主克课卡片 | 关系版三步一验算 + **内圈不能由你来克** + 两条铁律 |

**结论：八块模板 = 关系报告 v3 定稿骨架。用它整体替换现 B 模式叙事结构，四象限/证据对/功课包全部保留嵌入新骨架。自测报告 A 模式（M0–M14）不动。**

## 二、八块逐块对照（每块标注双池落点）

> 标记：✅引擎已有 　🔧已有需小改 　🆕全新 　📝预置文案（写作）　⚠️数据缺口

### R1 一页速览 🆕（双池落点：七行两池各归其主）
- **七行铁律**（每行 ≤30 字，一屏读完）：
  「关系：你（自测主型）与 TA（他测主型，在你眼中）／结构：生克组合／TA：第 N 层，阴/阳面主导（按你的判断）／你：第 N 层／卡点：X 断／这一句最像你们：____／下一步只做一件事：____」
- **灵魂句**：「这一句最像你们」——按「A 池 × B 池组合 × 断法」从预置句式库生成（📝模板 4.3 五句底稿入库）；**生成时优先引用两池中的实词**（如 TA 池中的阴面词 + 我的池中的阳面词，正是"我说的是关心，你听到的是指责"的词级素材）。
- 词域标注：七行只出行名/层号/断法名与预置句——天然合规。

### R2 两人坐标 🔧（双池落点：两池各撑一侧，严禁互串）
- 2.1 **TA 的坐标（池 B）**：主型判定（在你眼中 TA 是 X）+ 配比三行数字 + 阴阳 + 层位——全部来自他测卷；**措辞带"在你眼中"口径**。
- 2.2 **你的坐标（池 A）**：同表结构复用，词源换自测卷。
- 2.3 核心驱动力表：📝模板五行底稿入库；TA 行按他测主型查表、你行按自测主型查表；收束句「他要的和你给的不是一回事」由两行对比生成。
- 2.4 各自阴阳面（关系化 3–5 条）：🔧**池 B 阴面词**（他测主行 L7–9）与**池 A 阴面词**各按「词维度→关系表现」映射挑 top3–5（映射表📝共用）；写"在这段关系里的表现"，不写全清单。
- 词域标注：2.1/2.4-TA 侧只引池 B；2.2/2.4-我侧只引池 A——**双池纪律在此最严格**。

### R3 生克结构 🔧（双池落点：组合 = 自测主型 × 他测主型）
- 3.1 哪一组：✅组合判定已有；结论句「你们是 X 克 Y——你处在施克/被克位，TA（在你眼中）处在另一端」。**同行自对 5 组核验**（决策点 2）。
- 3.2 基本动力四段（怎么流动/天然好处/摩擦点/谁更难受）：📝25 组最大写作块，降量方案见决策点 3；**正文中嵌两池实词**（如金克木的摩擦点段，引"你确认的『挑剔』（池A）撞上你判断 TA 的『敏感』（池B）"）。
- 3.3 相生相克策略不同：📝常量表（模板底稿：相生=精简/节奏/无计划日；相克=先解一个结）。
- 3.4 同行自对专属判断：📝5 条（理解成本最低/盲区完全重合——**"你缺的那一块，TA 也没有"用两池对照可直证：两池中同维度词的空白**）。
- 词域标注：生克判定是结构层（行名组合）；正文嵌入词时遵守双池标签。

### R3.5 层面生克图谱 🆕（v1.2 新增核心模块，双池碰撞的落地产出）
- **定位**：把"你们是金克木"推进到"**生在哪里、克在哪里、为什么、怎么办**"——全报告引擎可算部分的最高价值输出。
- **四件套输出结构**（每份报告固定）：
  1. **关系判定**：自测主行 × 他测主行 → 生/克/自对（一句话+方向图示）；
  2. **原因说明**：这组生克的机制（预置 25 组文案，与 R3.2 复用）；
  3. **生克点清单**：按三段层面逐一切分——每个点 = 词对（池 A 词 × 池 B 词）+ 生/克价 + 一句原因；
  4. **对应策略**：生点配拔阴取阳落点、克点配化克为生落点（词对句式）。
- **生克价判定矩阵**（📝预置，引擎按此自动判价）：
  | 组合类型 | 阳面层面（L1–3 词对） | 中间层面（L4–6 词对） | 阴面层面（L7–9 词对） |
  |---|---|---|---|
  | 相生组（A 生 B） | **生点**（滋养成立） | 观察带（顺境无感） | **变相克点**（"优势过度出新问题"——生过头） |
  | 相克组（A 克 B） | **生点**（克得其所：边界成全生长——模板 3.2"克是让事情不失控的力量"） | 摩擦带（日常小磕碰） | **克点**（克过头：两池阴面词对撞，冲突主场） |
  | 同行自对 | 生点（同频共振） | 观察带 | **克点（盲区重合）**——你缺的那块 TA 也没有 |
- **报告呈现**：每段层面一节——先给该层面的总判定（相生/相克一句），再列 2–4 个词对点（每个点：词对+原因+策略），最多展示 2–4 个，**其余折叠进"更多生克点"**（同"卡点只给一个"的克制逻辑，防信息过载）；
- **词对选择规则**：池 A 取该层面答是词中维度权重最高者 × 池 B 同理；有 kePairs 现成证据对的优先采用；
- **策略落点规格**：
  - 生点 → 拔阴取阳：「你的『___』（池 A 阴面词）若拔向『___』（阳面去向），这个生点会更稳」——阳面去向来自五行转化表（预置）；
  - 克点 → 化克为生：「被克方养『Y 行』（第三行）：把『___』（池 B 克点词）的需求变成『___』（载体动作）」——载体四式（人/制度/动作/时机，预置）；
- 词域标注：全部走两池实词，标签随行——锚点规则 1/2 的直接实现。
- ⚠️依赖：两池词的「维度（xiang）」数据已有；判定矩阵与策略句式是预置写作块（矩阵 9 格 + 策略句式按生克组×层面，工作量中等）。

## 三、写作纪律合并稿（关系报告红线 v1.1）

八块模板六条 + 现有词域纪律 + 双池锚点，合并为十条：

0. **双池锚点（最高条）**：关系分析逻辑起点 = 自测主型答是词（池 A）+ 他测主型答是词（池 B）；两池分立、标签随行、池外词不进报告；
1. **他测池带投射口径**——描述 TA 一律"在你眼中/按你的判断"，不写"TA 就是"；
2. **只定位，不判对错**——报告不出现"谁的问题""谁该改"；
3. **一个人动只能改一半**——动作写成"你可以先做什么"，不写"你们必须"；
4. **卡点只给一个**——五种断法挑最主要，其余一句带过；
5. **层级决定语气**——7 层以上先谈停战不谈修复；
6. **内圈不用自己克**——最亲的关系里，克交给第三方；

## 五、需悟空裁定的决策点（认同框架时一并定）

1. **断法判定方案（R4 核心缺口）**：
   - A. **加一道轻自选题**（推荐）：出分后、报告前，弹一问「你们反复吵的那件事，最像下面哪一句？」五选一（即五断法典型句）。与模板口径一致、数据真实、改动轻。
   - B. 引擎纯推演：从两池词能量猜断法（如施克方金断多/被克方水断多）。零交互但易错——猜错则灵魂句全错。
   - C. 首版留白：断法不给，R1/R4/R5.3 降级。八块价值折损一半，不建议。
2. **同行自对核验**：engine_rel 是否已支持 5 组自对？不支持则第一批顺手补（改动小，默认做）。
3. **25 组生克动力文案**：A. 先手写 15 组（相克施克位 5 + 相生 10）+ 其余模板句式（推荐） / B. 25 组全手写 / C. 全模板生成。
4. **阴阳面「关系化 3–5 条」筛选**：按「词维度→关系表现」预置映射做（推荐是——否则只能整列阴面清单，违反模板"不写全部清单"）。
5. **双向差值「最大误解」是否进首版**（推荐进第三批——双向对填才有数据，价值最高但依赖条件多）。
6. **内圈判定**：不做自动判定，固定原则段呈现（推荐——"内圈"是差序格局概念，无客观数据可判，常量最稳）。
7. **旧关系篇去向**：八块结构**整体替换**现 B 模式叙事（推荐，四象限/证据对/功课包嵌入新骨架）；新旧并列不建议。

9. **生克点每层面展示上限**：每段 2–4 个词对、其余折叠（推荐 4 个上限——与"卡点只给一个"的克制逻辑一致，防信息过载）。

## 六、一句话总结

v1.2 把逻辑起点钉死在**两个词池**（池 A = 自测主型答是词，池 B = 他测主型答是词），并把双池碰撞升级为**可计算的产出规格**——「层面生克图谱」四件套：关系判定（固定生克环）→ 原因说明（预置文案）→ 生克点（三段层面 × 词对 × 生克价，判定矩阵自动判价）→ 对应策略（生点配拔阴取阳、克点配化克为生，全部围绕词对展开）。**引擎的词级证据对机制正是为此而生，锚点与引擎天然咬合**。八块骨架 + 双池锚点 + 层面生克图谱 + 一个断法自选题（推荐方案 A），关系报告 v3 即可开工。
