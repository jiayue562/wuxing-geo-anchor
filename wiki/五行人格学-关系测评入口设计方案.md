# 五行人格学·关系测评入口设计方案

> 版本：v1.0（2026-11-15）
> 依据：《五行人格学-关系分型测评报告结构设计.md》《五行人格学-关系测评体系方案.md》、起点规则（2026-11-15 悟空确认版）、已上线的五行人格在线测评一期系统（/wuxing/）
> 借鉴对象：MBTI（16personalities 式）测评入口页结构——顶部 Logo/标题 + 一句副标题 + **两张版本卡片并列** + 底部大按钮；及现有 /wuxing/ 宣传页的「说明文字 + 大按钮 + 断点续答说明」卡片结构。

---

## 一、设计目标

1. **测评直接作为入口页面**：进入关系测评即见「选窗口」的入口布局，不再套一层宣传长页——宣传信息压缩进入口页首屏。
2. **自测 / 他测双窗口并列**：入口页核心是两张卡片（对应 MBTI 站的「145题专业版 / 200题完整版」双卡结构），用户二选一进入。
3. **按五行分类答题、不混题不混编**：225 题按 木→火→土→金→水 分为五段，每段 45 题，**段内按词汇表原序（L1→L9）固定排列**，不做洗牌、不做跨行交错——一次只答一种能量，避免跨行语境切换导致的前后作答不一致。
4. **词为唯一原点**：沿用铁规——所有报告分析与措施只以答「是」的词为依据；起点规则（答是词中层位最深者为起点）全程适用。

### 2.2 卡片内容（文案初稿，待审定）

**卡片一 · 自测卷**
- 图标：🪞（照镜子）
- 主标题：自测卷
- 副标题：我测自己
- 题量行：225 题 · 约 25 分钟
- 说明一行：按 木→火→土→金→水 五段作答，看清自己的五行能量与九层位置。

**卡片二 · 他测卷**
- 图标：👥（看对方）
- 主标题：他测卷
- 副标题：我测 TA
- 题量行：225 题 · 约 25 分钟
- 说明一行：凭你对 TA 的了解作答，答完可与自测卷合并，生成关系报告。

**交互逻辑**：点卡片 → 卡片高亮选中（默认选中自测卷）→ 点「开始测评」进入对应答题页。他测卷点「开始测评」时先弹出一个小输入框：「你想为谁作答？（填称呼，如：爱人 / 老张 / 女儿，可不填）」——称呼用于后续双卷匹配与报告标题。

### 2.3 双卷状态显示（借鉴 MBTI 站「近30天测试」行）

每张卡片底部显示本机状态行（读 localStorage）：
- 自测卷：`未开始` / `已答 90/225` / `✅ 已完成 2026-11-15`
- 他测卷：`未开始` / `为「老张」已答 90/225` / `✅ 已完成`
- **两卷均完成时**：大按钮文字变为「**查看关系测评报告**」，金色高亮——这是关系测评的完整闭环点。

## 三、答题页面设计（/wuxing/rel/quiz.html）

### 3.1 五行分段结构（本方案核心）

```
总进度条（225 题，五段五色）
木 ■■■□□□□□□□ | 火 | 土 | 金 | 水    当前：木 · 第 12/45 题
─────────────────────────────────────
【木 · 答题区】第 1–45 题（共五段，当前第 1 段）
```

| 段 | 行 | 题号范围 | 题量 | 段内顺序 | 预计用时 |
|---|---|---|---|---|---|
| 1 | 木 | Q1–Q45 | 45 | L1→L9 固定原序 | 约 5 分钟 |
| 2 | 火 | Q46–Q90 | 45 | 同上 | 约 5 分钟 |
| 3 | 土 | Q91–Q135 | 45 | 同上 | 约 5 分钟 |
| 4 | 金 | Q136–Q180 | 45 | 同上 | 约 5 分钟 |
| 5 | 水 | Q181–Q225 | 45 | 同上 | 约 5 分钟 |

**不混题的三条实现规则**：
1. **段内不洗牌**：题目按词汇表原序排列（同一段内，L1 词在前、L9 词在后），无随机成分；
2. **段间不交错**：45 题木行全部答完才进入火行，绝无跨行穿插；
3. **段间过渡页**：每段答完出现过渡卡——「木行 45 题已完成 ✅　接下来：火行（45 题，约 5 分钟）」，用户点「继续」才进入下一段（也可先退出，进度已保存）。

### 3.2 每页 10 题、断点续答

- 沿用一期机制：每页 10 题、翻页、进度条、localStorage 自动保存；
- **存储键区分双卷**：
  - 自测卷：`wxr_v1_self`
  - 他测卷：`wxr_v1_other`（内含 `name` 称呼字段）
- 键内结构沿用一期：`{ ans: [...], page: n, startTs }`，另加 `order: "fixed-wood-first"` 标记（固定序版本标识，防止与一期洗牌版数据混用）。

### 3.3 自测卷与他测卷的差异

| 差异点 | 自测卷 | 他测卷 |
|---|---|---|
| 引导语 | 「下列陈述是否符合**你自己**的近期状态？」 | 「凭你对 **TA** 的了解，下列陈述是否符合 TA 的近期表现？」 |
| 题面 | 词汇陈述句（与一期相同） | **复用同一批陈述句**（决策点 R-1，见第八节） |
| 称呼 | 不需要 | 开始前填写（可不填，默认「TA」） |
| 报告 | 自测报告（模式 A 五板块） | 他测摘要报告 + 等待与自测卷合并 |
| 五段过渡页文案 | 「接下来是火行——你自己的火」 | 「接下来是火行——TA 的火」 |

## 四、完整测评流程（九步）

```
① 进入 /wuxing/rel/ 入口页
        ↓
② 选窗口：自测卡 或 他测卡
        ↓
③（他测）填被测者称呼
        ↓
④ 答题：木(45) → 火(45) → 土(45) → 金(45) → 水(45)
   每段间有过渡确认页，全程断点可续答
        ↓
⑤ 答完 → 生成单卷报告
   自测 → 自测报告（模式 A）
   他测 → 他测摘要报告
        ↓
⑥ 回入口页 → 另一卷状态行提示「完成另一卷可生成关系报告」
        ↓
⑦ 两卷都完成 → 大按钮变为「查看关系测评报告」（金色）
        ↓
⑧ 关系测评报告：四象限词级分布（共鸣/投射/防御/空白区）
   + 相生/相克分型判定（S/K 权分、起点规则）
   + 双线功课推荐（主生课 + 主克课 + 日课，B=MAP 卡）
        ↓
⑨（复测）三个月后重测，比对层级显现指标（K 降 ≥30% / S 维持 ≥95%）
```

**双卷匹配规则**（决策点 R-3）：同一浏览器内，自测卷（`wxr_v1_self`）与他测卷（`wxr_v1_other`）各自完成即视为一对「关系数据」；他测卷可更换称呼重测（存 `wxr_v1_other_2`…），报告页顶部提供「选择用哪一份他测卷合并」。

## 五、报告页面设计（/wuxing/rel/report.html）

一个页面、三种形态，按已有数据自动切换：

| 形态 | 触发条件 | 内容（对应既有设计文档） |
|---|---|---|
| 自测报告 | 只完成自测卷 | 模式 A 五板块（总纲/三界/五行/九层/象思维）+ 起点建议（三模型流水线） |
| 他测摘要 | 只完成他测卷 | 答题者视角标注 + TA 的五行分布与九层定位摘要 + 「完成自测卷可解锁关系篇」提示 |
| **关系报告** | 双卷均完成 | 测他摘要 + **关系篇三节**：①四象限词级分布表（共鸣/投射/防御/空白区）②相生/相克判定（S/K 权分排序、起点规则、平局乐观基线）③90 天关系行动地图（首月只做共鸣区；主生课+主克课+日课，B=MAP 卡） |

关系报告沿用「判定过程全透明」铁规：每个分型结论都附证据对表（哪些词、双方各答什么、层位、权分如何算出），可回溯。

## 七、五行分段的设计理由（回应「避免前后答题不一致」）

1. **语境聚焦**：一次只面对一种能量（如连答 45 道木行题），作答者保持在同一参照系内，减少跨行跳跃带来的联想漂移；
2. **结构叙事**：木→火→土→金→水 正是相生序，答题过程本身就是一次「能量巡行」，与测评理论同构；
3. **固定原序防定势的取舍**：一期自测卷用洗牌交错防止「连续答是」的定势偏差；关系版改为分段固定序后，同词九题（同一原象词 L1–L9）会在段内连续出现——这**不是缺陷而是设计**：同一词的九层阶梯连排，正好呈现「从解放到病态破坏」的完整光谱，降低漏答与误判（决策点 R-2 复核点）；
4. **时长友好**：每段约 5 分钟，段间过渡页给用户明确的「休息点」，支持随时退出。

## 八、决策点（R-1 ～ R-6）

| 编号 | 决策 | 建议 |
|---|---|---|
| R-1 | 他测题面：复用自陈陈述句（只换引导语）vs 每题改写第三人称 | **建议复用**——225 词为形容词性陈述（如「积极乐观」），第三人称可直接读；改写 225 题成本高且引入两套口径 |
| R-2 | 段内顺序：词汇表原序（L1→L9）vs 段内轻微打散 | **建议原序**——九层阶梯连排有教学价值；若实测发现明显「连是」定势，二期再加段内隔位 |
| R-3 | 双卷匹配：同浏览器自动匹配 vs 要求两卷连续完成 | **建议同浏览器自动匹配**（localStorage 同源），宽松友好 |
| R-4 | 书院首页是否同步加「关系测评」入口 | 建议二期上线时在门户「核心知识库」加第二张卡，与一期入口并列 |
| R-5 | 一期主卷入口保留 vs 下线 | **建议保留**——两者定位不同（单卷自照 / 关系工作） |
| R-6 | 关系报告的 S/K 权分参数（层位分、区位系数等）一期先按体系方案初值上线，实测后校准 | 按方案第四章公式初值执行 |

## 九、实施步骤（开发顺序）

1. **数据层**：data.js 增加五行分段索引（按 e 分组、段内按词汇表序）；引擎扩展双卷读取与四象限计算；
2. **入口页**：rel/index.html（双卡 + 大按钮 + 状态行）；
3. **答题页**：rel/quiz.html（五段固定序 + 过渡页 + 双卷键 + 称呼输入）；
4. **报告页**：rel/report.html（三形态；一期报告渲染逻辑复用，关系篇新增）；
5. **本地验证**：模拟自测卷完成 / 他测卷完成 / 双卷完成三场景 + 断点续答 + 段间过渡；
6. **部署**：`wrangler pages deploy docs`（沿用 OAuth 凭据）→ 验证线上 /wuxing/rel/ 三页面与双卷流程；
7. **门户入口**：docs/index.html 加「关系测评」卡（R-4）；
8. **Git 同步**推送 GitHub main。
