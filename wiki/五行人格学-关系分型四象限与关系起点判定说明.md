# 五行人格学——关系分型四象限与关系起点判定说明

> 版本：V1.0（配套说明文档）
> 日期：2026-11-15
> 主文档：《五行人格学-关系分型测评报告结构设计.md》
> 用途：面向报告使用者（施测者、解读师、受测者）解释四象限从哪里来、关系起点为什么是共鸣区、四个象限的内容怎么读。

---

## 一、乔哈里窗是什么，我们借它什么

乔哈里窗（Johari Window）把「一个人对自己的认知」与「他人对这个人的认知」交叉成四个区域：公开区（双方都知道）、盲目区（别人知道我不知道）、隐藏区（我知道别人不知道）、未知区（双方都不知道）。它给关系改善留下一条经典路径：**通过自我暴露缩小隐藏区、通过接受反馈缩小盲目区，从而扩大公开区——公开区越大，关系越扎实。**

五行人格学借它三样东西：

1. **两维交叉的窗结构**——但两维换成我们自己的窗口：自测窗口与测他窗口；
2. **四象限的动力学含义**——联结、误解、防御、潜能；
3. **「扩大公开区」的改善方向**——即「从共鸣区出发」的关系起点纪律。

借的是结构与动力学，不借它的词表与计分——**我们的四个象限里装的，全部是 225 词终审定稿中受测者选出的词**。

---

## 二、四象限的划分逻辑：词是唯一的划分单元

关系测评有两个窗口、两张卷子、同一个 225 词表：

- **自测窗口**：答题者答自评版 225 题，选出「我身上的词」；
- **测他窗口**：答题者答他评版 225 题，选出「我眼中对方身上的词」。

于是同一个词在双卷上有四种「是/否」组合，恰好穷尽四个象限——**一个词落进哪个象限，只由这两次作答决定，不由任何其他因素决定**：

```
                    他测窗口选出（是）
                    ┌─────────────────┬─────────────────┐
                    │   共鸣区          │   防御区          │
 自测窗口选出（是）  │  我认己，亦见人    │  我有，对方未见    │
                    │ （公开区）        │ （隐藏区功能位）   │
                    ├─────────────────┼─────────────────┤
                    │   投射区          │   空白区          │
 自测窗口未选（否）  │  他在，我未认己    │  双方都未激活      │
                    │ （盲目区功能位）   │ （未知区）        │
                    └─────────────────┴─────────────────┘
```

- **共鸣区**（自测是 ∧ 他测是）：我承认自己有、也在对方身上看见——双方共有的词，是关系的共同语言。
- **投射区**（自测否 ∧ 他测是）：我在对方身上选出的词，自己却没选——可能是对方的真实特质，也可能是「我看不见的自己」借看他人显形（乔哈里盲区的动力学位置）。
- **防御区**（自测是 ∧ 他测否）：我身上呈现、我在对方身上找不到的词——我未被对方看见、回应的部分（乔哈里隐藏区的动力学位置）。
- **空白区**（双否）：双方都未激活——关系的未开发区。因为答「否」不做个体推断，空白区只做行 × 层聚合统计，不逐词呈现。

**命名说明**：为什么投射区/防御区不直接叫盲目区/隐藏区——因为测他窗口评的是对方这个人，不是「对方眼中的我」，四象限装的是两个窗口的词谱交集，不是标准乔哈里窗的自知/他知。我们保留的是它的四区**动力学**（误解、防御、潜能、联结），故按动力学功能位命名。若启用双向互测（二期，决策点 J1），每人即得一份标准乔哈里窗，届时可用标准命名。

## 三、关系起点：为什么是共鸣区（公开区）

**关系的起点与出发点 = 共鸣区。** 三层理由：

**理由一：它是唯一双方都在场的区域。** 共鸣区的词，答题者认己、亦见人——双方共识，是关系中最没有争议的地基。关系分析从这里出发，结论不会被「你根本不了解我」推翻。

**理由二：关系分型的判定以它为第一证据。** 相生/相克的判定，第一步只统计共鸣区的证据对；只有共鸣区分不出胜负时才启用投射区、防御区的证据。这意味着关系类型的结论，首先建立在「双方共同选出的词」之上——这正是「词为唯一原点」原则在判定顺序上的体现。

**理由三：关系行动的第一个月只做共鸣区。** 90 天关系行动地图的第一个月里程碑，只安排共鸣区措施（增益或化克为生）；第二个月才加入投射区求证、第三个月处理防御区暴露。先地基、后扩区，是乔哈里窗「扩大公开区」路径的顺序化。

**扩区方向（共鸣区如何长大）：**

```
        投射区 ──求证与自照──→ 共鸣区 ←──暴露表达── 防御区
```

- 投射区的词经「求证＋自照」确认为双方共有 → 落入共鸣区；
- 防御区的词经「暴露表达」被对方看见回应 → 落入共鸣区；
- 两个方向都在扩大共鸣区——与乔哈里窗经典路径完全同构。

## 四、关系分型判定方法：三步走（面向使用者）

**第一步 · 看证据对表。** 报告列出每一对跨窗口的词：我方词（层位）｜对方词（层位）｜构成生还是克。判定只认表里列出的对——表外的话不算数。

**第二步 · 记住两条判定口径。**
- **生**：一方阳面词（健康段选出）生对方阳面词——健康能量在滋养关系；
- **克**：一方**阴面词**（一般段、不健康段选出）克对方**阳面词**——阴伤阳才是损伤。
- 双方阳面对阳面的克**不是**相克证据——那是关系中的调节与磨合（书稿口径：生克＝增强/调节回路）。别把「一个急性子配一个慢性子」判成相克关系。

**第三步 · 看判定顺序。** 共鸣区证据先行（差 ≥ 2 出结论）；接近时全量证据再算；仍平局时按乐观基线判相生并建议复测。报告会标注平局事实，解读时如实转达即可。

**判定结果怎么用：**
- **相生关系型**：报告给生链图（我的哪个词养着对方的哪个词）＋增益措施——把生链互动固化成习惯锚点。相生关系也有阴面词，照常进共鸣区病灶清单，不因「相生」而跳过。
- **相克关系型**：报告给克链图（我的哪个阴面词正在伤对方的哪个阳面词）＋化克为生措施——在克源词上落主行通关点＋替换微行为。克源词是我可以改的那一端，这就是关系里「我能做的部分」。

## 五、四个象限的解读要点（使用者手册）

| 象限 | 读什么 | 解读纪律 |
|---|---|---|
| 共鸣区 | 先分阳面词（资产）与阴面词（共同病灶）；资产看生链、病灶看克链 | 关系主战场；第一个月只在这里工作 |
| 投射区 | 词数多 = 我对对方的「看见」里混着自己未承认的部分；先求证（以具体事例核对），再自照（答「否」是事实还是防御） | **不得据此给对方贴标签**——投射区的词未经求证前只是假设 |
| 防御区 | 词数多 = 我在这段关系里「未被看见感」强；呈现词数与分布即可把这种感受结构化，避免泛化指责 | 措辞是「我未被看见的部分」，不是「对方不了解我」 |
| 空白区 | 只读聚合统计：「我们还没启用的相处方式有哪些」 | 不逐词、不对号入座；只在关系僵局时给 1–3 条低强度探索建议 |

**一条总纪律（词为唯一原点）**：解读时每句话都落在具体词上；讲不出词名的判断不要说。这是报告的规则，也是解读师的规则。

## 六、常见疑问

**Q1：测他窗口是我评对方，那这报告是不是「我以为的关系」而非「真实的关系」？**
是「我以为的关系」——这正是单向模式的边界，报告在测他窗口摘要处明示：「以下为答题者眼中的对方，非对方的自知」。真实度靠两个机制逼近：投射区求证练习（拿词去与对方核实）；二期双向互测（对方也自测＋评我），届时每人才有一份标准乔哈里窗。

**Q2：一个词我自己答「是」、也觉得对方有，但对方未必觉得自己有——共鸣区还是共识吗？**
是「答题者视角的共识」。单向下它是关系分析可用的最扎实证据（答题者同时认己与认人），但它仍是答题者的判断，不是两人共识的确认版。报告措辞用「共鸣」不用「双方确认」，边界就守住了。

**Q3：相生关系型是不是就不用改了？**
不是。相生关系型的报告里，共鸣区阴面词的克证据照常列出、照常给化克为生措施——「相生」说的是关系的主导走向，不是免检标签。

**Q4：为什么平局判相生？**
乐观基线是设计选择：判定拿不准时，把关系往「可改善」的方向解读，配合复测机制收敛结论。若你担心误判，可改选「不出类型、显示待复测」（决策点 J2）。

**Q5：空白区那么大（双方未选的词通常过百），会不会没意义？**
它的意义恰恰在聚合层：哪一行、哪一层的词整体未被启用，说明那段相处方式是这对关系的空白。它给的是「还有哪些可能」，不是「你们缺什么」——后者会变成指责，前者才是资源。
